# M01 Reference Spec V1.0

M01 se denomina LEER ANTES DE VENDER.

Competencia primaria: interpretación.

Principio: comprender la situación antes de convertirla en una solución.

Las seis visitas usan a Tomás, Luciano, Marina, Matías, Carla y Federico con funciones pedagógicas diferentes: introducción, contraste, momento de la necesidad, ambigüedad contextual, transferencia e integración.

M01 no debe organizarse alrededor de un único producto. El motor definitivo debe evaluar el recorrido conversacional completo y no sólo la acción final.

ASK_MORE es una acción de conversación y no una decisión terminal.

La versión detallada de las seis MASTER VISIT CARD se redactará antes de migrar M01 al nuevo engine.
