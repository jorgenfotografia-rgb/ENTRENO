# Pedagogical System V1.0

## Ciclo de aprendizaje
RECONOCER → ESCUCHAR → PREGUNTAR → INTERPRETAR → VERIFICAR → DECIDIR → EXPLICAR → RECORDAR

Cada verbo representa una habilidad diferente. Academy no debe premiar adivinanzas: debe premiar descubrimiento y criterio.

## Competencias
1. Reconocimiento: identificar clientes recurrentes y nivel de relación.
2. Escucha: detectar objetivo, problema y contexto.
3. Pregunta: obtener la información que falta.
4. Interpretación: separar pedido de necesidad.
5. Traducción: conectar lenguaje cotidiano, técnico, ingredientes, categorías y productos.
6. Criterio: decidir producto, categoría, preguntar más, no vender o derivar.
7. Comunicación: explicar sin exagerar ni confundir.
8. Memoria comercial: recordar información útil sin convertirla en prejuicio.

## Capas de información
### Observable
Lo que puede verse. Nunca habilita por sí solo una recomendación ni una inferencia de salud/necesidad.

### Declarada
Lo que el cliente expresa espontáneamente.

### Oculta
Lo que sólo aparece mediante preguntas relevantes.

## Regla de memoria
> Recordar permite preguntar mejor. Nunca permite asumir.

La memoria se clasifica como STABLE, TEMPORARY o TO_CONFIRM.

## Comprador y usuario final
Buyer y end user son entidades separadas. Academy debe entrenar explícitamente que quien compra puede no ser quien consume.

## Modos pedagógicos
### Training mode
Puede ofrecer feedback inmediato sobre relevancia, timing, confianza o información faltante sin revelar necesariamente la solución.

### Evaluation mode
No muestra feedback intermedio. La lectura aparece al final de la visita.

## Principio de dificultad
La dificultad aumenta retirando ayudas y agregando ambigüedad, recurrencia, lenguaje técnico, terceros, contradicciones, clientes informados y múltiples necesidades.

## Resultado esperado
Academy debe cambiar conductas observables de mostrador, no sólo incrementar conocimiento declarativo.
