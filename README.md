# PITBULL ACADEMY · PRODUCT QUALITY PASS 01

Objetivo: que la experiencia se sienta como una app publicada, no como una demo gráfica.

## Principios
- Academy = sistema estable.
- Marca / producto = contenido variable.
- Interfaz inspirada en la disciplina de ENTRENO, no en sus funciones.
- Amarillo reservado a acción, selección y progreso.
- Tiby aparece sólo en The Boss Check y The Boss Review.
- Consecuencia del cliente antes del aprendizaje.
- Persistencia local: el usuario puede cerrar y continuar luego.
- Base PWA preparada para instalación / publicación.
